# Unit 1: Introduction to Artificial Intelligence & Retrieval-Augmented Generation (RAG)

## 1. What is RAG (Retrieval-Augmented Generation)?
Retrieval-Augmented Generation (RAG) is an architectural framework that enhances Large Language Models (LLMs) by retrieving relevant facts from an external knowledge base (vector database) before generating a response.
Key benefits of RAG:
- Reduces LLM hallucinations by grounding responses in factual user documents.
- Enables LLMs to access private, real-time, or proprietary context (such as PDFs, PPT presentations, and medical records).
- Cost-effective alternative to full model fine-tuning.

## 2. Vector Databases and Embeddings
Vector databases like FAISS (Facebook AI Similarity Search) and ChromaDB store high-dimensional numerical vectors (embeddings) generated by Transformer models (e.g. sentence-transformers/all-MiniLM-L6-v2).
- Cosine Similarity and L2 Distance are used to calculate semantic similarity between query vectors and document chunk vectors.
- Text Splitters: RecursiveCharacterTextSplitter breaks raw documents into overlapping chunks (e.g., 600 characters with 100 overlap) to preserve semantic context across chunk boundaries.

## 3. Ollama & Local LLMs
Ollama is a lightweight local runner for open-weight Large Language Models such as Mistral-7B, LLaMA 3, and Gemma.
- Mistral-7B features grouped-query attention (GQA) and sliding window attention (SWA) for fast inference and 8k context length.

## 4. Evaluation Metrics for AI Models
- Precision = True Positives / (True Positives + False Positives)
- Recall = True Positives / (True Positives + False Negatives)
- F1-Score = 2 * (Precision * Recall) / (Precision + Recall)
